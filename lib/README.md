# PURPOSE

Python and Bash libraries directory for running the provenance framework, RECORD.

# MANIFEST

+ `__init__.py` - this tells Python that this is a directory containing Python packages.
+ `__init__.pyc` - Python generated.
+ `README.md` - This file containing purpose of files in this directory and manifest
+ `record.py` - Python code for the metadata library.
+ `record.pyc` - Python byte code for record library.
+ `record.sh` - The bash code to invoke the above python library.
